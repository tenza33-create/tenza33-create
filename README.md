## 🚀 Proyectos Destacados

### 📂 1. Automatización ETL de Cuadrantes e Informes
> **Procesamiento de datos complejos en hojas de cálculo y generación automática de informes en PDF/Word.**

* **📌 Descripción:** Scripts en Python diseñados para procesar cuadrantes y registros estructurados en Excel, realizando limpieza de datos, filtrado por entidad e integración de datos.
* **🛠️ Tecnologías:** `Python`, `Pandas`, `OpenPyXL`, `VS Code`.
* **🔄 Proceso y Aprendizaje:** 
  - Limpieza y estructuración de tablas heterogéneas.
  - Automatización de tareas repetitivas reduciendo tiempos de procesamiento a segundos.
  - Generación de documentos dinámicos a partir de datos procesados.
* **🔗 Enlaces:** [Ver Repositorio](https://github.com/tenza33-create/cuadrante-web)
